# Feynman Companion AI Agent — 项目上下文（第六周）

## 项目简介

费曼伴学智能体，一个基于费曼学习法（输出倒逼输入）的考研 AI 辅导工具。用户**讲解知识点**给 AI 小白听众，AI 通过多轮追问找出用户理解漏洞，最终生成**四维诊断报告**。

---

## 当前完成功能（第五周末）

### 1. 账号体系（后端 B 陈艺博）
- User 表（id, username, password_hash, created_at）
- JWT 鉴权（HS256, 24h 过期）
- `POST /api/v1/auth/register` — 注册
- `POST /api/v1/auth/login` — 登录返回 token
- `GET /api/v1/auth/current` — 当前用户信息
- `guest` 游客用户自动创建，无 token 访客默认归属 guest

### 2. 鉴权依赖（后端 B 陈艺博）
- `backend/app/api/dependencies.py`：
  - `get_current_actor()` — 从 Bearer Token 解码，返回 CurrentActor（含 user_id, username, is_guest）
  - `require_current_user()` — 拦截游客，强制登录
- 所有费曼接口（greeting/chat/reset/sessions）和资源接口（material/kp）均注入 `Depends(get_current_actor)`

### 3. 教材解析管线（后端 A 马茗燕）
- `POST /api/v1/material/upload` — 上传 PDF，后台异步解析
- 管线：PyMuPDF 提取 → 切片（~500字/块）→ LLM 抽取知识点 → LLM 生成四维 rubric
- `GET /api/v1/material/{id}/status` — 轮询解析进度
- `GET /api/v1/material/tree?subject=` — 科目→教材→章节→知识点 四级树
- `GET /api/v1/material/{id}/retrieve` — RAG 语义检索
- `POST /api/v1/material/{id}/embedding/rebuild` — 重建向量
- `DELETE /api/v1/material/{id}` — 删除教材（同步清理向量 + PDF）
- `POST /api/v1/material/{id}/retry` — 解析失败重试
- `GET/POST/PATCH/DELETE /api/v1/kp/...` — 知识点 CRUD + rubric 重新生成

### 4. 四张表 user_id 数据隔离（后端 A 马茗燕）
- Material/Chapter/Chunk/KP 均有 `user_id` 字段（默认 `'guest'`）
- 所有查询按 user_id 过滤（material_service + kp_service）
- pdf_service 创建记录时传 user_id
- extraction_service 创建 KP 时从 Material 继承 user_id
- 存量迁移 SQL 自动补 user_id

### 5. RAG 语义检索（后端 A 马茗燕）
- ChromaDB PersistentClient + BAAI/bge-large-zh-v1.5 embedding
- `VectorStoreService`：add_chunks / search / delete_material
- `ChromaRAGRetriever` 实现了 `RAGRetriever` 协议，接入 LangGraph
- 检索范围限定单教材（`vec_mat_{material_id}` collection）

### 6. 会话持久化 + LangGraph（后端 B 陈艺博）
- `SQLSessionStore` 替代内存存储，会话写入 `learn_session` 表
- LearnSession 表：id, user_id, kp_id, material_id, messages_json, final_response_json
- LangGraph 流程：
  1. load_context → 2. route_input → 3. retrieve（RAG 检索） → 4. evaluate（LLM 评判）/ report（生成报告） → 5. persist_session
- 最多 3 轮追问，DeepSeek 失败降级 MockLLM

### 7. 四维诊断报告
- 维度：理解深度 / 表达完整性 / 逻辑连贯性 / 结构化能力（各 0-10 分）
- 报告包含：card_preview（总分+摘要）+ final_report（四维详细评分+评语）

## 技术栈

| 层 | 技术 |
|---|---|
| 后端框架 | Python 3.13 + FastAPI + Uvicorn |
| ORM | SQLModel（SQLAlchemy 之上） |
| 数据库 | SQLite（feynman.db，项目根目录） |
| 对话引擎 | LangGraph（线性状态机） |
| LLM | DeepSeek V4 Pro（主）+ MockLLM（降级） |
| 向量库 | ChromaDB（chroma_db/ 目录） |
| Embedding | BAAI/bge-large-zh-v1.5（SentenceTransformers） |
| 鉴权 | PyJWT HS256 + passlib bcrypt |
| 前端 | Vue 3 + Vite + Pinia + ECharts |

## 开发注意事项

1. **各端文件零冲突**：后端 A/B 改不同的文件，只有 main.py 各加 1-2 行代码
2. **数据库生命周期**：`core/database.py` 中 `create_db_and_tables()` 在应用启动时自动执行
3. **Mock 数据**：所有接口在 `get_settings().material_mock` 为 True 时返回 Mock 数据，方便前端并行开发
4. **guest 兼容**：`user_id='guest'` 的用户跳过漏洞和报告写入，学情弹窗不弹出
5. **漏洞去重规则**：同一 `user_id + kp_id + dimension + status='open'` 不重复创建，仅更新 score
6. **Swagger 调试**：`http://localhost:8000/docs` — 先点 Authorize 填 `Bearer {token}` 再调接口
